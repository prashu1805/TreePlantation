# 🌳 Tree Plantation Awareness Project

This is a simple web project designed to raise awareness about tree plantation. It includes a static front-end created using **HTML** and **CSS**, highlighting the importance of planting trees and encouraging users to take part in green initiatives.

---

## 📌 Features

- Informative homepage about the importance of trees
- Responsive design for mobile and desktop
- Attractive visuals with nature-themed styling
- Call to action for planting trees
- Basic form for user engagement (e.g., pledge to plant a tree)

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- (Optional) Google Fonts or simple animations
